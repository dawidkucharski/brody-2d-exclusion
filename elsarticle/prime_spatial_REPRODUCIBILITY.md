# Prime Spatial Analysis: Reproducibility

This package accompanies the manuscript on embedding-dependent nearest-neighbour
statistics. The input is generated by sieving the integers up to 99,856; no
external dataset is required. The primary executable analysis is
`prime_spatial_analysis.py`, and `prime_spatial_results.json` records its output.

## Environment

The reported run used Python 3.9.6, NumPy 2.0.2, SciPy 1.13.1 and Matplotlib
3.9.4. A LaTeX installation with `elsarticle`, `natbib`, `bibtex` and `latexmk`
is required to compile the manuscript. A compatible Python environment can be
prepared with:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy==2.0.2 scipy==1.13.1 matplotlib==3.9.4
```

## Run

From the directory containing the package:

```sh
python -m unittest -v test_prime_spatial_analysis
python prime_spatial_analysis.py
python power_calibration.py
python power_level_check.py
python seismic_application.py
python build_prime_figures.py
latexmk -pdf -interaction=nonstopmode -halt-on-error aurora_manuscript.tex
```

`power_calibration.py` writes `power_calibration.json` and
`fig_power_calibration.pdf`; it calibrates the paired edge-contrast procedure
under planted gap-class enrichment (2,000 null realisations and 400 per
alternative at the default settings). Its thresholds are fixed at the
Gaussian $\pm1.96$; no empirical critical value is estimated from the null
sample. `power_level_check.py` repeats the null phase with a second seed
(20261102) and writes `power_level_check.json`, so the reported type-I error
estimates do not reuse the calibration's null ensemble. Both files are checked
by `test_manuscript_power_table_if_present` and
`test_independent_level_check_if_present`.

`seismic_application.py` implements the Section-4 application: it rasterises
the cached U.S. Geological Survey ANSS catalogue (`seismic_events_ca.csv.gz`,
magnitude $\ge2.5$, California region, 2000--2026; 37,590 events) onto a
$96\times96$ cell grid, builds the nested rook and queen adjacency graphs,
computes the exact null variance of Eq. (5), and runs 1,999 paired fixed-count
realisations. It writes `seismic_application.json` and
`fig_seismic_application.pdf`. If the cached catalogue is missing, the script
refetches it in yearly windows from the USGS FDSN endpoint and caches it. The
results are checked by the `SeismicApplicationTests` class.

The full analysis took approximately 11 minutes on the machine used for this
revision; the power calibration takes of the order of an hour at the default
sizes. The existing JSONs permit figures to
be rebuilt without rerunning the simulations. The root seed is `20261101`,
and independent streams are constructed using NumPy `SeedSequence`. The JSON
records actual sample sizes and software versions: 4,999 paired fixed-count
realisations, 1,000 mapped inhomogeneous realisations, 2,000 shell and
open-graph validation realisations, 200 descriptor null summaries, 1,000 boundary
nulls, and 2,000 descriptive
distance resamples. Thinning uses 500 masks per non-native density and 1,000
Bernoulli controls; finite-window nulls use 1,000 or 200 draws as stated in the
manuscript. Reproduction at the last decimal may depend on library versions.

## Scope Of Checks

The regression tests verify hand-checked 4-by-4 embeddings, the three large
bijections, the prime count, periodic nearest neighbours and annular counts
against direct enumeration, fixed-count
shell expectations and paired graph variances against exhaustive small-grid
enumeration for regular and irregular graphs, inhomogeneous calibration, the
corrected border estimator, and histogram-based Brody, empirical-CDF and
multiscale calculations against independent formulations. The final pipeline was executed
for the recorded output; this is not a claim that every simulation has been
independently repeated by a separate implementation.

The Brody fit is a quasi-likelihood descriptor, not a continuous joint model
for dependent, tied lattice distances. Its empirical-CDF discrepancies and
largest tie fractions are recorded in the JSON. The resampled distance
intervals are descriptive: nearest-neighbour distances are dependent. The
random-labelling Monte Carlo values are conditional on the
fixed-count null, selected maps and window; no correction for prior selection
of alternative analyses is claimed. The inhomogeneous comparison has a random
count and is a separate model. The finite-scale slopes are not asymptotic
dimensions.

The current analysis and its tests do not import the older audit scripts.
The earlier `audit_v4_verify.py`, `REPRODUCIBILITY_AUDIT.md` and
`REVISION_LOG.md` contained incorrect verification claims and are superseded;
they must not be used as evidence that the earlier manuscript passed.

All ten manuscript figures are vector PDF files. The descriptor benchmark,
finite-scale, thinning and ablation analyses are collected in the manuscript's
supplementary appendix together with the power-calibration rates. The
package is released as version 2.0.0 in the GitHub repository
https://github.com/dawidkucharski/brody-2d-exclusion and archived on Zenodo
with DOI 10.5281/zenodo.23940935 (concept DOI 10.5281/zenodo.23940934). The
repository was brought up to date with this revision on 2026-11-04.
